---
Title: How to update
---
Learn how to update your website.

## Update in a web browser

1. Open your website in a web browser.
2. Log in with your user account, preferably with the webmaster account.
3. Go to the settings and check for updates.
4. Your website will show if updates are available.
5. Click `Update`.

If you want to learn more about the latest changes, [see what's new](what-s-new).

## Update at the command line

1. Open a terminal window.
2. Go to your installation folder, where the file `yellow.php` is.
3. Type `php yellow.php update`.
4. Your website will show if updates are available.
5. Type `php yellow.php update all`. 

If you have problems with the update, [see product information](product-information) and [troubleshooting](troubleshooting).
